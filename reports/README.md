# CPX 커버리지 감사

상세 JSON 보고서는 생성 산출물이므로 Git에는 넣지 않는다. 다음 명령으로 같은 기준의 보고서를 재생성한다.

```bash
python3 tools/audit_cpx_coverage.py \
  --base /tmp/medagent-kb-build/kb-2026.10.13.1 \
  --output reports/cpx-coverage-kb-2026.10.13.1.json
```

| 지표 | 기초판 `kb-2026.10.08.2` | 보강판 `kb-2026.10.13.1` |
|---|---:|---:|
| CPX 연결 질환 | 1,876 | 1,876 |
| 기전 없음 | 147 | 131 |
| 직접 소견만 | 229 | 212 |
| 물리 진찰 징후 없음 | 357 | 355 |
| 전역/스키마 제한 결과가 다른 질환 | 371 | 396 |

마지막 행은 오류 수나 성능 점수가 아니다. 공유 기전 노드를 전역으로 따라갈 때와 주호소 스키마 문맥을 유지할 때 결과가 달라지는 질환 수다. 보강 간선이 여러 주호소에 근거를 명시하면서 이 진단 지표는 늘 수 있다. 실제 조회는 스키마 제한이 기본이다.
